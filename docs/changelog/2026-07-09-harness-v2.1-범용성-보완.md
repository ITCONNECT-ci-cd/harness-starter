# 2026년 7월 9일 — 하네스 v2.1: 범용성 보완

**대상 독자**: 비개발자 포함 — "어떤 프로젝트에서도 안전하게 적용 가능"을 목표로
외부 검토에서 발견된 빈틈을 보완했습니다.

## 한 줄 요약

설치 안전망(백업·.gitignore 자동 병합), 검증 설정의 bash/PowerShell 통일,
안전장치가 조용히 꺼지는 문제의 가시화, 보안 설정 강화 — 4개 축을 손봤습니다.

## 무엇이 바뀌었나

### 1. 설치(install.sh)가 더 안전해졌습니다

- **`--force` 덮어쓰기 전 자동 백업**: 기존 파일/폴더를 `.harness-backup/<시각>/`에
  보관한 뒤 덮어씁니다. 이전에는 폴더를 통째로 지우고 교체해서, 프로젝트가 그
  폴더에 추가해 둔 자체 파일이 사라질 수 있었습니다. 이제 폴더는 삭제 없이
  **overlay 병합**(템플릿 파일만 갱신, 자체 파일 보존)합니다.
- **.gitignore 자동 병합**: `private/`(내부정보), `state/db-backups/`(DB 덤프) 등
  하네스 필수 제외 규칙을 대상 프로젝트 .gitignore에 자동으로 추가합니다.
  이전에는 이 규칙이 template 저장소에만 있어서, install.sh로 설치한 프로젝트에서
  내부정보·DB 덤프가 실수로 커밋될 수 있었습니다.

### 2. 검증 설정이 bash/PowerShell 어디서나 동일하게 동작합니다

- `harness.validate.json`(mode/commands/required)을 이제 **validate.sh(bash)도
  인식**합니다. 이전에는 PowerShell만 읽어서, 같은 프로젝트인데 Windows(Phase A)와
  bash(Phase B)가 서로 다른 검증 명령을 쓸 수 있었습니다.
- project mode 계약("필수 명령이 없으면 SKIP이 아니라 실패")도 bash에 구현.
  비 npm 스택(Python/Go 등)은 `commands`에 스택 명령을 지정하면 됩니다.
- pnpm/yarn/bun 프로젝트 자동 감지(lockfile 기준)를 bash에도 추가.

### 3. 안전장치가 "조용히 꺼지는" 문제를 가시화했습니다

- Claude 훅(위험 명령 차단, docker/DB 가드, 편집 후 lint)은 `jq`가 없으면
  동작할 수 없습니다. 이제 없으면 **경고를 출력**하고, `doctor.ps1` 점검 항목에도
  jq가 추가됐습니다.
- 위험 명령 차단(block-rm)이 `rm -r -f`, `rm --recursive --force` 같은 **플래그
  변형도 차단**합니다. `mkfs` 패턴이 매칭되지 않던 잠재 버그도 수정.
- 세션 시작 시 활성 교훈(feedback-rules) 안내가 실제로 AI 컨텍스트에 주입되도록
  출력 채널을 수정했고, 규칙 0개일 때 발생하던 카운트 버그도 고쳤습니다.

### 4. 보안·유지보수 설정 강화

- Trivy 액션 버전 고정(`@master` → `@v0.36.0`) — 공급망 리스크 제거.
- gitleaks 예외 목록 축소: 문서(docs)·워크플로우(.github) 전체 제외를 걷어내고,
  하네스가 배포하는 규칙 문서 디렉터리만 좁게 제외. 프로젝트가 추가하는 문서는
  이제 전부 시크릿 스캔 대상입니다.
- `.agents/skills`와 `.claude/skills` 두 스킬 트리의 **동기화를 self-test가 강제**
  (그동안 `db-backup-setup` 스킬이 Codex 쪽에만 있어 Claude에서 못 쓰던 드리프트 수정).
- LICENSE(MIT) + THIRD-PARTY-NOTICES(BMAD/WDS 번들 고지) 추가.

### 5. 문서를 현실에 맞게 정리

- CLAUDE.md가 규칙 문서 14개를 매 세션 전부 로드하던 것을 **핵심 6개만 로드**하고
  나머지는 "상황별 규칙" 표로 전환 — 세션당 수만 토큰 절약.
- CI 워크플로우 헤더가 "자동 트리거 전제"로 쓰여 있던 것을 실제 기본값
  (수동 실행, 복원 방법은 docs/harness/ci-cd.md)에 맞게 수정.
- 특정 AI 모델명 하드코딩 제거 (모델명은 빨리 낡음).
